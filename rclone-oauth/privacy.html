Privacy policy

This OAuth client is for personal use only by the application owner.

Data accessed

When authorized, the application can access Google Drive files belonging to the signed-in Google account, solely so rclone can mount and sync that account’s Drive on the owner’s computer.

Data storage

Access tokens are stored locally on the owner’s machine in rclone’s encrypted configuration. No Drive file contents are uploaded to this website. This site hosts only this policy text.

Sharing

Drive data is not sold, published, or shared with third parties by this application. Google’s own processing is governed by Google’s privacy policy.

Contact

Questions: contact the project owner via their GitHub account.
